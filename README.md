# CPP-Graphics-Functions-Tutorial
# المرجع الشامل لدوال الرسوميات (graphics.h) - الإصدار 3.1

وثيقة تفاعلية ودليل برمجي مُنظم يحتوي على توثيق مفصل وشرح عملي لـ **41 دالة** من دوال مكتبة `graphics.h` المستخدمة في لغة C++. تم إعداد وتطوير هذا المشروع ليكون مرجعاً سريعاً وشاملاً في المختبرات العملية لمقرر **الرسم بالحاسوب (Computer Graphics)**.

---

## ميزات الدليل (إصدار 3.1)

* **تقسيم موضوعي ذكي:** تم توزيع الدوال الـ 41 على 6 مجموعات رئيسية (التهيئة، خصائص الشاشة، الألوان، الحركة، رسم الأشكال، والنصوص).
* **واجهة تفاعلية (TOC):** فهرس مرن في مقدمة الصفحة يسمح بالانتقال السريع لأي دالة بضغطة زر.
* **تنسيق برمي احترافي:** إبراز الصيغ العامة (Syntax) واستخدام مكتبة `Prism.js` لتلوين الأكواد البرمجية وتسهيل قراءتها.
* **دعم كامل للطباعة:** تم بناء استعلامات مخصصة للطباعة (`@media print`) تخفي العناصر غير الضرورية (مثل زر الصعود والفهرس) وتنسق بطاقات الدوال لتظهر بشكل مثالي عند طباعتها ورقياً أو تصديرها كـ PDF.
* **تجربة مستخدم سلسة:** إضافة زر عائم ذكي للعودة إلى أعلى الصفحة بسلاسة (Scroll-to-top).
