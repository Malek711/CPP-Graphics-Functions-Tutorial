1. التهيئة والتحكم بالنظام
initgraph 1
الفكرة:لتشغيل وضع الرسوميات (Graphics Mode) وفتح النافذة.
الشكل العام:initgraph(&gd, &gm, path);
المعاملات:
  • &gd: متغير لتحديد مشغّل الرسوميات (استخدم DETECT).
  • &gm: متغير لحالة وضع الرسوميات.
  • path: مسار مجلد السائق BGI (اتركه فارغاً "").
ملاحظات: هذه أول دالة يجب استدعاؤها. إنها تهيئ بيئة الرسم.
مثال بسيط: 
int gd = DETECT, gm;
initgraph(&gd, &gm, ""); // فتح شاشة الرسم
closegraph 2
الفكرة:إغلاق نافذة الرسم وإنهاء وضع الجرافيكس.
الشكل العام:closegraph();
المعاملات:
  • (لا يوجد)
ملاحظات: يجب استدعاؤها دائماً عند الانتهاء لتنظيف الذاكرة وإغلاق النافذة بشكل آمن.
مثال بسيط: 
delay(5000); // انتظر 5 ثوانٍ
closegraph(); // إغلاق النافذة الآن
cleardevice 3
الفكرة:مسح محتويات الشاشة بالكامل (بشكل أساسي لون الخلفية).
الشكل العام:cleardevice();
المعاملات:
  • (لا يوجد)
ملاحظات: تُستخدم كثيراً عند الحاجة لمسح الشاشة وبدء رسم جديد، خاصة في الرسوم المتحركة.
مثال بسيط: 
circle(100, 100, 50); // رسم دائرة
delay(1000);
cleardevice(); // الدائرة اختفت الآن
delay 4
الفكرة:إيقاف تنفيذ البرنامج مؤقتاً بالملي ثانية (ms).
الشكل العام:delay(ms);
المعاملات:
  • ms: عدد الملي ثواني للإيقاف.
ملاحظات: تستخدم في الرسوم المتحركة لإبطاء الحركة وجعلها مرئية.
مثال بسيط: 
outtext("Wait...");
delay(3000); // انتظر 3 ثوانٍ
outtext("Go!");
2. خصائص الشاشة والإحداثيات
getmaxx 5
الفكرة:إرجاع أقصى إحداثي س (X) يمكن الوصول إليه على الشاشة.
الشكل العام:int max_x = getmaxx();
المعاملات:
  • (لا يوجد)
ملاحظات: العرض الكلي للشاشة هو getmaxx() + 1. تستخدم للتوسيط.
مثال بسيط: 
int center_x = getmaxx() / 2;
circle(center_x, 100, 50); // رسم دائرة في المنتصف الأفقي

int center_y = getmaxy() / 2;
circle(100, center_y, 50); // رسم دائرة في المنتصف العمودي

int max_c = getmaxcolor();
setcolor(max_c); // اختيار اللون الأقصى (الأبيض عادةً)

lineto(100, 100);

مثال بسيط: 
putpixel(10, 10, RED);
if (getpixel(10, 10) == RED) { /* ... */ } // شرط يتحقق
3. الألوان والتعبئة
setcolor 11
الفكرة:تغيير لون الرسم الأمامي (القلم) للأشكال والنصوص القادمة.
الشكل العام:setcolor(color);
المعاملات:
  • color: رقم اللون (من 0 إلى 15).
ملاحظات: هذا اللون سيستخدم في line، circle، outtext، إلخ.
مثال بسيط: 
setcolor(BLUE); // اختيار اللون الأزرق
line(0, 0, 100, 100); // رسم خط أزرق
setbkcolor 12
الفكرة:تغيير لون خلفية الشاشة (Back Ground Color).
الشكل العام:setbkcolor(color);
المعاملات:
  • color: رقم اللون.
ملاحظات: لتطبيق اللون الجديد، يجب استدعاء cleardevice() أو bar().
مثال بسيط: 
setbkcolor(YELLOW);
cleardevice(); // الآن صارت الخلفية صفراء
getcolor 13
الفكرة:إرجاع رقم اللون الحالي للرسم (اللون الذي تم اختياره بـ setcolor).
الشكل العام:int c = getcolor();
المعاملات:
  • (لا يوجد)
ملاحظات: يستخدم لحفظ اللون مؤقتاً قبل تغييره ثم استعادته لاحقاً.
مثال بسيط: 
int old_c = getcolor(); // حفظ اللون القديم
getbkcolor 14
الفكرة:إرجاع رقم لون الخلفية الحالي.
الشكل العام:int bk = getbkcolor();
المعاملات:
  • (لا يوجد)
ملاحظات: يفيد عند الحاجة إلى تعيين لون حدود التعبئة ليكون مطابقاً للون الخلفية.
مثال بسيط: 
int bg = getbkcolor();
setfillstyle(SOLID_FILL, bg); // استخدام نفس لون الخلفية للتعبئة
setfillstyle 15
الفكرة:تحديد نمط (Pattern) ولون التعبئة للأشكال المغلقة.
الشكل العام:setfillstyle(pattern, color);
المعاملات:
  • pattern: شكل التعبئة (مثل SOLID_FILL, HATCH_FILL).
  • color: لون التعبئة.
ملاحظات: تُستخدم قبل دوال التعبئة مثل bar, fillpoly, وfloodfill.
مثال بسيط: 
setfillstyle(HATCH_FILL, RED); // تعبئة مشبكة حمراء
floodfill 16
الفكرة:تعبئة منطقة مغلقة باللون والنمط المُختارين (كأنها دلو طلاء).
الشكل العام:floodfill(x, y, border);
المعاملات:
  • x, y: نقطة داخل المنطقة المراد تعبئتها.
  • border: لون الخط الحدودي للمنطقة.
ملاحظات: إذا كان اللون (color) داخل الدالة setfillstyle مطابقاً للحدود (border) فلن تعمل الدالة.
مثال بسيط: 
circle(100, 100, 30);
floodfill(100, 100, WHITE); // تعبئة الدائرة البيضاء
setpalette 17
الفكرة:تعديل درجة لون معين (Index) في النظام إلى لون آخر (Actual Color).
الشكل العام:setpalette(index, color);
المعاملات:
  • index: رقم اللون المراد تعديله (مثل RED).
  • color: القيمة اللونية الجديدة (من 0 إلى 63).
ملاحظات: تستخدم في الأوضاع المتقدمة لتغيير الدرجات اللونية الأساسية (الباليت).
مثال بسيط: 
setpalette(4, 2); // رقم 4 (الأحمر) سيصبح رقم 2 (الأخضر)
setcolor(RED); // سيستخدم الآن اللون الأخضر!
4. التحكم في المؤشر (CP)
moveto 18
الفكرة:نقل المؤشر الرسومي (CP) إلى إحداثي س، ص (x, y) محدد دون رسم.
الشكل العام:moveto(x, y);
المعاملات:
  • x, y: الإحداثيات الجديدة المطلقة للمؤشر.
ملاحظات: هذه تحدد نقطة البداية لدوال مثل lineto و outtext.
مثال بسيط: 
moveto(50, 50); // نقل المؤشر
lineto(100, 50); // رسم خط من (50,50) إلى (100,50)
moverel 19
الفكرة:نقل المؤشر الرسومي (CP) مسافة نسبية من موقعه الحالي.
الشكل العام:moverel(dx, dy);
المعاملات:
  • dx: التغيير في إحداثي س (X).
  • dy: التغيير في إحداثي ص (Y).
ملاحظات: الحركة نسبية. moverel(20, 0) تعني تحرك 20 بكسل لليمين.
مثال بسيط: 
moveto(100, 100);
moverel(0, 50); // يصبح الموقع (100, 150)
5. دوال الرسم والأشكال
putpixel 20
الفكرة:رسم نقطة واحدة (Pixel) باللون المختار.
الشكل العام:putpixel(x, y, color);
المعاملات:
  • x, y: إحداثيات النقطة.
  • color: لون النقطة.
ملاحظات: أساس الرسوميات. تستخدم في الخوارزميات الدقيقة مثل رسم خط بريسنهام.
مثال بسيط: 
putpixel(10, 10, WHITE); // رسم نقطة بيضاء في الأعلى اليسار
line 21
الفكرة:رسم خط مستقيم بين نقطتين معلومتين.
الشكل العام:line(x1, y1, x2, y2);
المعاملات:
  • x1, y1: نقطة البداية.
  • x2, y2: نقطة النهاية.
ملاحظات: لا تعتمد على المؤشر (CP)، وتستخدم اللون المحدد بـ setcolor.
مثال بسيط: 
line(0, 0, 100, 100); // رسم خط قطري
lineto 22
الفكرة:رسم خط مستقيم من موقع المؤشر الحالي (CP) إلى نقطة جديدة.
الشكل العام:lineto(x, y);
المعاملات:
  • x, y: الإحداثيات المطلقة لنقطة النهاية.
ملاحظات: بعد الرسم، يتم تحديث موقع المؤشر (CP) ليصبح هو نقطة النهاية (x, y).
مثال بسيط: 
moveto(50, 50);
lineto(150, 50); // يرسم خط أفقي، ويصبح المؤشر (150, 50)
linerel 23
الفكرة:رسم خط مستقيم من موقع المؤشر الحالي (CP) بمسافة نسبية.
الشكل العام:linerel(dx, dy);
المعاملات:
  • dx, dy: التغيير النسبي في الإحداثيات.
ملاحظات: مفيدة لرسم أشكال بسيطة دون الحاجة لحساب الإحداثيات النهائية في كل مرة.
مثال بسيط: 
moveto(100, 100);
linerel(0, 50); // يرسم خط عمودي لأسفل بطول 50 بكسل
rectangle 24
الفكرة:رسم إطار (حدود) مستطيل فارغ.
الشكل العام:rectangle(left, top, right, bottom);
المعاملات:
  • left, top: إحداثيات الزاوية العلوية اليسرى.
  • right, bottom: إحداثيات الزاوية السفلية اليمنى.
ملاحظات: لا يتم تعبئة المستطيل، ويتم الرسم بلون setcolor وبنمط setlinestyle.
مثال بسيط: 
rectangle(10, 10, 100, 50); // رسم صندوق فارغ
bar 25
الفكرة:رسم مستطيل معبأ باللون والنمط المُحددين مسبقاً.
الشكل العام:bar(left, top, right, bottom);
المعاملات:
  • left, top: الزاوية العلوية اليسرى.
  • right, bottom: الزاوية السفلية اليمنى.
ملاحظات: يعتمد على إعدادات setfillstyle. لا يرسم إطار خارجي بل يملأ فقط.
مثال بسيط: 
setfillstyle(SOLID_FILL, GREEN);
bar(10, 10, 100, 50); // رسم مربع أخضر صلب
bar3d 26
الفكرة:رسم عمود/مستطيل ثلاثي الأبعاد معبأ.
الشكل العام:bar3d(l, t, r, b, depth, topflag);
المعاملات:
  • l, t, r, b: إحداثيات الزوايا (مثل bar).
  • depth: عمق العمود (بالبكسل).
  • topflag: رسم سقف للعمود (1=نعم، 0=لا).
ملاحظات: يُستخدم لرسم المخططات البيانية ثلاثية الأبعاد.
مثال بسيط: 
bar3d(100, 100, 200, 250, 20, 1); // عمود بعمق 20
circle 27
الفكرة:رسم دائرة فارغة بالإحداثيات ونصف القطر.
الشكل العام:circle(x, y, r);
المعاملات:
  • x, y: إحداثيات مركز الدائرة.
  • r: نصف قطر الدائرة.
ملاحظات: يتم الرسم باللون setcolor.
مثال بسيط: 
circle(200, 200, 50); // دائرة بمركز (200, 200) ونصف قطر 50
arc 28
الفكرة:رسم قوس (جزء من دائرة) غير مغلق.
الشكل العام:arc(x, y, st_ang, end_ang, r);
المعاملات:
  • x, y: مركز القوس.
  • st, end: زاوية البداية والنهاية (درجات).
  • r: نصف القطر.
ملاحظات: الزاوية 0 تقع عند الساعة 3 وتدور عكس عقارب الساعة.
مثال بسيط: 
arc(200, 200, 0, 90, 50); // رسم ربع دائرة (قوس)
pieslice 29
الفكرة:رسم قطاع دائري (شريحة فطيرة) معبأ.
الشكل العام:pieslice(x, y, st, end, r);
المعاملات:
  • نفس معاملات arc.
ملاحظات: يربط القوس بالمركز ويملأ الشكل بنمط setfillstyle.
مثال بسيط: 
setfillstyle(SOLID_FILL, YELLOW);
pieslice(200, 200, 0, 60, 100); // شريحة صفراء
ellipse 30
الفكرة:رسم قوس أو شكل بيضاوي كامل.
الشكل العام:ellipse(x, y, st, end, xr, yr);
المعاملات:
  • x, y: إحداثيات مركز الشكل.
  • st, end: زاوية البداية والنهاية (بالدرجات).
  • xr, yr: نصف القطر الأفقي والعمودي.
ملاحظات: لرسم شكل بيضاوي كامل، اجعل الزاويتين 0 و 360.
مثال بسيط: 
ellipse(200, 200, 0, 360, 100, 50); // شكل بيضاوي كامل
fillellipse 31
الفكرة:رسم شكل بيضاوي معبأ (لا يمكن رسم قوس).
الشكل العام:fillellipse(x, y, xr, yr);
المعاملات:
  • x, y: إحداثيات مركز الشكل.
  • xr, yr: نصف القطر الأفقي والعمودي.
ملاحظات: لا يرسم حدوداً خارجية بل يملأ باللون والنمط المُختارين من setfillstyle.
مثال بسيط: 
fillellipse(200, 200, 50, 25); // بيضاوي معبأ
sector 32
الفكرة:رسم قطاع بيضاوي معبأ (نسخة مطورة من pieslice).
الشكل العام:sector(x, y, st, end, xr, yr);
المعاملات:
  • xr, yr: نصف القطر الأفقي والعمودي (مثل ellipse).
ملاحظات: يُستخدم لرسم شرائح بيضاوية الشكل.
مثال بسيط: 
sector(300, 200, 0, 120, 100, 50); // قطاع بيضاوي
drawpoly 33
الفكرة:رسم حدود مضلع (Polygon) باستخدام قائمة نقاط.
الشكل العام:drawpoly(points, array);
المعاملات:
  • points: عدد النقاط الكلي في المصفوفة.
  • array: مصفوفة تحتوي الإحداثيات بالتتابع (x1, y1, x2, y2, ...).
ملاحظات: لرسم مضلع مغلق، يجب تكرار نقطة البداية في نهاية المصفوفة.
مثال بسيط: 
int pts[] = {100,10, 200,100, 50,100, 100,10};
drawpoly(4, pts); // رسم حدود مثلث مغلق (4 نقاط)
fillpoly 34
الفكرة:رسم مضلع معبأ (يتم إغلاقه تلقائياً قبل التعبئة).
الشكل العام:fillpoly(points, array);
المعاملات:
  • points: عدد النقاط الكلي في المصفوفة.
  • array: مصفوفة الإحداثيات.
ملاحظات: لا تحتاج إلى تكرار نقطة البداية في النهاية، ويستخدم setfillstyle.
مثال بسيط: 
int pts[] = {100,10, 200,100, 50,100};
fillpoly(3, pts); // تعبئة المثلث بثلاث نقاط فقط
setlinestyle 35
الفكرة:تغيير شكل الخط (سمك، نمط) للأشكال المرسومة.
الشكل العام:setlinestyle(style, pattern, thick);
المعاملات:
  • style: نمط الخط (مثل SOLID_LINE, DOTTED_LINE).
  • pattern: قيمة مخصصة (0 للأنماط القياسية).
  • thick: سمك الخط (مثل NORM_WIDTH, THICK_WIDTH).
ملاحظات: تؤثر هذه الإعدادات على line، circle، rectangle، إلخ.
مثال بسيط: 
setlinestyle(DOTTED_LINE, 0, THICK_WIDTH);
line(0, 50, 200, 50); // خط منقط وسميك
6. التعامل مع النصوص
outtext 36
الفكرة:كتابة نص في موقع المؤشر الرسومي الحالي (CP).
الشكل العام:outtext("Text");
المعاملات:
  • "Text": النص المراد عرضه.
ملاحظات: بعد الكتابة، يتم تحديث المؤشر (CP) إلى نهاية النص المكتوب.
مثال بسيط: 
moveto(100, 100);
outtext("Hello"); // كتابة "Hello" ابتداءً من (100, 100)
outtextxy 37
الفكرة:كتابة نص في موقع س، ص (x, y) محدد بشكل مباشر.
الشكل العام:outtextxy(x, y, "Text");
المعاملات:
  • x, y: إحداثيات بداية النص.
  • "Text": النص المراد عرضه.
ملاحظات: لا تعتمد على المؤشر (CP) ولا تغيّره.
مثال بسيط: 
outtextxy(50, 200, "Score: 100"); // كتابة في موقع ثابت
settextstyle 38
الفكرة:تحديد شكل الخط (Font)، اتجاهه (Direction)، وحجمه (Size).
الشكل العام:settextstyle(font, dir, size);
المعاملات:
  • font: نوع الخط (مثل TRIPLEX_FONT).
  • dir: اتجاه الخط (أفقي HORIZ_DIR أو عمودي VERT_DIR).
  • size: عامل التكبير (1 للحجم الأصلي، 2 للتكبير مرتين، إلخ).
ملاحظات: يجب استدعاؤها قبل outtext أو outtextxy ليتم تطبيق النمط.
مثال بسيط: 
settextstyle(TRIPLEX_FONT, HORIZ_DIR, 3);
outtext("Big Text"); // يظهر النص كبيراً 3 مرات
textwidth 39
الفكرة:حساب عرض النص المحدد بالبكسل (Pixel Width).
الشكل العام:int w = textwidth("Text");
المعاملات:
  • "Text": النص المراد قياس عرضه.
ملاحظات: تستخدم أساساً لتوسيط النصوص في الشاشة. تأخذ في الاعتبار إعدادات settextstyle الحالية.
مثال بسيط: 
int x_center = (getmaxx() - textwidth("GO")) / 2;
outtextxy(x_center, 100, "GO"); // توسيط النص
textheight 40
الفكرة:حساب ارتفاع النص المحدد بالبكسل (Pixel Height).
الشكل العام:int h = textheight("Text");
المعاملات:
  • "Text": النص المراد قياس ارتفاعه.
ملاحظات: تستخدم لترتيب النصوص عمودياً (سطر تلو سطر) بشكل دقيق مع مراعاة حجم الخط.
مثال بسيط: 
int h = textheight("Line");
outtextxy(10, 10, "Line 1");
outtextxy(10, 10 + h, "Line 2"); // بدء السطر الثاني تحت الأول تماماً
sprintf 41
الفكرة:تنسيق وكتابة البيانات (أرقام، متغيرات) إلى سلسلة نصية (String).
الشكل العام:sprintf(buffer, "format", variable, ...);
المعاملات:
  • buffer: مصفوفة الأحرف التي سيتم تخزين النص المنسق فيها.
  • "format": شكل التنسيق (مثل "%d" للأعداد الصحيحة).
  • variable: المتغيرات المراد تنسيقها.
ملاحظات: لا ترسم النص مباشرة، بل تعدّه. يجب استخدام outtext أو outtextxy لعرضه لاحقاً.
مثال بسيط: 
char buffer[30];
int score = 100;
sprintf(buffer, "Score: %d", score); // buffer يصبح "Score: 100"
outtextxy(10, 10, buffer); // طباعة النتيجة
7. ملخص نظري سريع

أساسيات التهيئة والتحكم

لبدء العمل مع الرسوميات، تحتاج لتهيئة وضع BGI. استخدم دائماً DETECT كقيمة لمشغّل الرسوميات (gd) ليقوم النظام باكتشاف الإعدادات الأفضل تلقائياً. تأكد من إغلاق النظام بـ closegraph() في النهاية.

نظام الإحداثيات والقياسات

في مكتبة graphics.h، نقطة الأصل (0, 0) تقع في الزاوية العلوية اليسرى من الشاشة.

  • المحور X (الأفقي): يبدأ من 0 ويزداد كلما اتجهنا لليمين.
  • المحور Y (العمودي): يبدأ من 0 ويزداد كلما اتجهنا لأسفل.

يمكنك استخدام getmaxx() و getmaxy() لتحديد حجم منطقة الرسم الحالية لتوسيط الأشكال.

الألوان الأساسية (0 - 15)

تعتمد المكتبة على استخدام أرقام لتمثيل الألوان الأساسية. القيمة الافتراضية للرسم هي الأبيض (15) وللخلفية هي الأسود (0).

أرقام الألوان الشائعة:

  • 0: BLACK (أسود)
  • 1: BLUE (أزرق)
  • 2: GREEN (أخضر)
  • 3: CYAN (سماوي)
  • 4: RED (أحمر)
  • 5: MAGENTA (أرجواني)
  • 6: BROWN/YELLOW (بني/أصفر)
  • 7: LIGHTGRAY (رمادي فاتح)
  • 15: WHITE (أبيض)

المؤشر الرسومي (Current Position - CP)

المؤشر الرسومي هو إحداثي س، ص (x, y) داخلي يتم تتبعه بواسطة النظام. دوال مثل moveto وlineto وouttext تغير موقعه، بينما دوال مثل line وcircle لا تغيره.
